← Finance-ში დაბრუნება

სამი ასლი. ერთი ისტორია.

ამ ტელეფონში შენახვა ავტომატურად მუშაობს. Google Drive და Dropbox შენს ანგარიშებთან ერთჯერად დაკავშირებას საჭიროებს. ქვემოთ მოცემული ინსტრუქციის შესრულებამდე არც მესამე ასლი და არც დახურული აპის შეტყობინებები ჩართულად არ ითვლება.

სამი დამოუკიდებელი ადგილი: ტელეფონი, Google Drive და Dropbox. ტელეფონის ორი ბრაუზერული საცავი ერთი ადგილია. გარე ასლის წარმატება დადასტურდება მხოლოდ ჩაწერილი ფაილის უკან წაკითხვის შემდეგ.

1 · Google Drive
  1. გახსენი შენი არსებული Google Apps Script პროექტი. ძველი კოდი სრულად შეცვალე განახლებული სკრიპტით. ერთ პროექტში ძველი და ახალი doPost ერთდროულად არ დატოვო.

    სკრიპტის ჩამოტვირთვა

  2. Project Settings → Script properties-ში შეინახე FINANCE_TOKEN — ახალი შემთხვევითი საიდუმლო, მინიმუმ 32 სიმბოლო. ძველი საჯაროდ გაზიარებული ტოკენი აღარ გამოიყენო. ტოკენი მხოლოდ შენს Script Properties-სა და აპის პარამეტრებში შეინახე.
  3. Deploy → Manage deployments → Edit → New version → Deploy. აირჩიე Execute as: Me; Who has access: Anyone. მოთხოვნებს საიდუმლო ტოკენი ამოწმებს. პირველად მიეცი შენს სკრიპტს Drive-ის ნებართვა.
  4. Finance → პარამეტრები → ონლაინ Backup-ში ჩაწერე სრული https://script.google.com/macros/s/…/exec მისამართი და ახალი ტოკენი.
  5. დაელოდე „Google Drive — მზადაა“ სტატუსს. შენს Drive-ში იქნება FinanceAppBackupsV3, ან წინა ვერსიის უკვე დაკავშირებული საქაღალდე.

ყოველი ვერსია ცალკე ფაილია. ძველი გარე ასლები ავტომატურად არ იშლება; საცავის თავისუფალი ადგილი პერიოდულად შეამოწმე.

2 · დამოუკიდებელი მესამე ასლი — Dropbox
  1. Dropbox App Console-ში შექმენი Scoped access → App folder აპი. სრული Dropbox-ის წვდომა საჭირო არ არის. Permissions-ში ჩართე files.content.write და files.content.read, შემდეგ Submit.
  2. Dropbox-ის Settings-იდან App key და App secret შეინახე Google-ის იმავე სკრიპტის Script Properties-ში სახელებით DROPBOX_APP_KEY და DROPBOX_APP_SECRET. ისინი საჯარო კოდში არ ჩაწერო.
  3. აქ ჩაწერე მხოლოდ საჯარო App key, რომ ავტორიზაციის ბმული მიიღო. Secret ამ გვერდზე არ ჩაწერო.

  4. ბმულზე შესვლისა და ნებართვის შემდეგ Dropbox-ის ნაჩვენები ერთჯერადი კოდი ჩაწერე Script Properties-ში როგორც DROPBOX_AUTH_CODE. შემდეგ Script editor-იდან გაუშვი connectDropboxOnce. ის შეინახავს განახლებად ტოკენს და ერთჯერად კოდს წაშლის. კოდი ხანმოკლეა — თუ ვადა გაუვიდა, მიიღე ახალი.
  5. Finance-ში დააჭირე „გადამოწმება / გაგზავნა“. დაელოდე 3/3 დამოუკიდებელ ადგილს. Dropbox-ში ნახავ აპის კერძო საქაღალდესა და JSON ასლს.

მხოლოდ დროებითი „Generated access token“ საკმარისი არ არის მუდმივი ავტომატური შენახვისთვის. ინსტრუქცია იყენებს offline access-სა და refresh token-ს. არც ავტორიზაციის კოდი და არც საიდუმლო გასაღები არ გამომიგზავნო ჩატში.

3 · ტელეფონის შეტყობინებები დახურული აპის დროსაც

შეტყობინებებს აგზავნის Firebase Cloud Messaging. საათობრივი Google-ის გამშვები ამოწმებს ვადებს მაშინაც, როცა Finance დახურულია. შეტყობინებები აჩვენებს მხოლოდ გადასახადების რაოდენობას — სახელებისა და თანხების გარეშე.

  1. Firebase Console-ში შექმენი ან აირჩიე შენი პროექტი, დაამატე Web app და დააკოპირე მისი საჯარო კონფიგურაცია. სკრიპტის Script Properties-ში FIREBASE_PUBLIC_CONFIG-ის მნიშვნელობა უნდა იყოს JSON ობიექტი apiKey, projectId, messagingSenderId, appId ველებით. ეს არის ვებაპის საჯარო კონფიგურაცია, არა service account-ის პირადი ფაილი.
  2. Project settings → Cloud Messaging → Web Push certificates → Generate key pair. საჯარო Key pair ჩაწერე Script Property-ში FIREBASE_VAPID_PUBLIC_KEY.
  3. Project settings → Service accounts → Generate new private key. მიღებული JSON შეინახე მხოლოდ Script Property-ში FIREBASE_SERVICE_ACCOUNT. არ ჩაწერო ის საჯარო რეპოზიტორიაში ან ამ ვებგვერდზე. შესაბამის პროექტში Firebase Cloud Messaging API და FCM Registration API ჩართული უნდა იყოს; service account-ს შეტყობინებების გაგზავნის უფლება უნდა ჰქონდეს.
  4. Script editor-ში გაუშვი installFinanceScheduler და მიეცი აუცილებელი ნებართვები. შეიქმნება ერთი საათობრივი გამშვები. ის ასევე ხელახლა სცდის Dropbox-ის დაუმთავრებელი ასლების გაგზავნას. საჭიროების შემთხვევაში Deploy-ში კვლავ აირჩიე New version.
  5. შენს ტელეფონში Chrome-ით გახსენი Finance → პარამეტრები → ტელეფონის შეტყობინებები. აირჩიე საათი და დროის სარტყელი, შემდეგ „ამ ტელეფონზე ჩართვა“ და დაუშვი შეტყობინებები.
  6. გააგზავნე სატესტო შეტყობინება. დარწმუნდი, რომ რეალურად გამოჩნდა ტელეფონზე. სერვერის „გაგზავნილია“ პასუხი თავისთავად მიწოდების დადასტურება არ არის.

შემოწმება საათობრივია, ამიტომ არჩეულ საათზე ზუსტად წუთში მიწოდება გარანტირებული არ არის. შეტყობინებას ქსელმა, Android-ის ბატარეის რეჟიმმა ან ბრაუზერის ნებართვამ შეიძლება შეუშალოს ხელი. სერვერი იყენებს ბოლო დასინქრონებულ მდგომარეობას — ოფლაინში მონიშნული გადახდა ჯერ ვერ ეცოდინება. გადაცილებულზე მოდის მაქსიმუმ ერთი შეჯამება დღეში თითო ტელეფონზე, სანამ არ მონიშნავ გადახდას.

დამატებითი ფაილი ტელეფონის მეხსიერებაში

პარამეტრები → „Backup ფაილი“ ჩამოტვირთავს JSON ასლს Downloads-ში. „JSON ასლის გაზიარება“ გახსნის ტელეფონის გაზიარების ფანჯარას, თუ ბრაუზერი მხარს უჭერს. ფაილი შეგიძლია სხვა საცავშიც შეინახო. გაზიარების ფანჯრის გახსნა ან ჩამოტვირთვის მოთხოვნა დადასტურებულ გარე ასლად არ ჩაითვლება.

სასარგებლოა პერიოდულად ასლის კომპიუტერზე ან USB დისკზეც შენახვა. Samsung Cloud-ის მიერ ბრაუზერის ფინანსური ბაზის შენახვას ეს აპი ვერ ამოწმებს და მას ავტომატურად მესამე ასლად არ ჩათვლის.

განახლება და მონაცემების შენარჩუნება

გამოიყენე იგივე მისამართი და იგივე ბრაუზერი. ახალი ვერსიის ჩასატვირთად დახურე Finance-ის ყველა ფანჯარა და ხელახლა გახსენი. ბრაუზერის მონაცემები არ გაასუფთავო. ადგილობრივი ისტორია და საწყისი ბალანსები შენარჩუნებულია. საწყისი ბალანსის შეცვლა შეგიძლია პარამეტრების ზედა ღილაკიდან.

„არასდროს დაიკარგება“ გარანტია არც ერთ სისტემას არ აქვს. სამი დამოუკიდებელი ასლი, შენახული ვერსიები, შემოწმებული გაგზავნა და შენს ხელში არსებული JSON ფაილი ამცირებს რისკს. ასლების მდგომარეობას ყოველთვის შეხედე: მიზანია 3/3.
