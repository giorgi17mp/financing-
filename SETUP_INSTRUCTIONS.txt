Finance — არსებული აპის განახლება v7

იგივე მისამართი და იგივე ბრაუზერი გამოიყენე. ბრაუზერის მონაცემები არ გაასუფთავო.
ძველი finance_final_*_v6 ჩანაწერები ერთჯერადად გადაიტანება ახალ საცავში.
ძველი გასაღებები უცვლელად დარჩება; პირადი ისტორია HTML-ში აღარ არის ჩაშენებული.
თუ ძველი მონაცემი ვერ იკითხება, ავტომატური ჩანაცვლება შეჩერდება.

ადგილობრივი დაცვა
• IndexedDB-ში ერთიანი ტრანზაქცია, SHA-256 შემოწმება, ვერსიების ისტორია.
• localStorage-ში დამატებითი ასლი; ბრაუზერის მონაცემების წაშლა ორივეს წაშლის.
• შეინახე JSON ფაილი Google Drive-ში ან სხვა მოწყობილობაზე პერიოდულად.
• CSV მხოლოდ ცხრილის ექსპორტია; აღდგენისთვის გამოიყენე JSON.
• ახალ ვერსიას სჭირდება თანამედროვე HTTPS ბრაუზერი, არა ჩამოტვირთული file:// HTML.

Google Drive ონლაინ ასლის ერთჯერადი განახლება
1. გახსენი შენი არსებული Google Apps Script პროექტი.
2. ჩაანაცვლე სკრიპტი ამავე რეპოზიტორიის GoogleDriveBackupV2.gs ფაილით.
3. Project Settings → Script properties-ში დაამატე FINANCE_TOKEN:
   ახალი, შემთხვევითი, მინიმუმ 32 სიმბოლო. არ ჩაწერო ტოკენი საჯარო კოდში.
   ძველი საჯაროდ გაზიარებული ტოკენი აღარ გამოიყენო.
4. Deploy → Manage deployments → Edit → New version → Deploy.
   Execute as: Me. Who has access: Anyone. წვდომა ჩაიწერება მხოლოდ სწორი ტოკენით.
   პირველად ავტორიზაცია მიეცი შენსავე Google Drive-ზე.
5. აპში პარამეტრები → ონლაინ Backup: ჩაწერე /exec URL და ახალი პირადი ტოკენი.
6. დაელოდე „ონლაინ ასლი დადასტურებულია“ სტატუსს. თუ არ ჩანს, ასლი დადასტურებული არ არის.

სკრიპტი ქმნის კერძო FinanceAppBackupsV2 საქაღალდეს შენს Drive-ში.
ყოველი გაგზავნა ცალკე JSON ფაილია, იგივე ID-ით გამეორებული გაგზავნა დუბლიკატს არ ქმნის.
ძველი ფაილები არ იშლება. Drive-ის სივრცე პერიოდულად შეამოწმე.
აპი აგზავნის ბოლო მდგომარეობას, როდესაც გახსნილია და ინტერნეტი ხელმისაწვდომია.
მოწყობილობის დაკარგვისგან დაცვა არსებობს მხოლოდ გარეთ რეალურად შენახული ასლისთვის.

განახლების ნახვა
თუ PWA ძველ ეკრანს აჩვენებს, დახურე ამ აპის ყველა ფანჯარა/ჩანართი და ხელახლა გახსენი.
არ გამოიყენო Clear site data, Reset ან ხელახალი ინსტალაცია მონაცემების ექსპორტამდე.

ფუნქციები
• თვის მიმოხილვა, კატეგორიის ბიუჯეტები, USD/GEL ცალკე აღრიცხვა.
• სრული საძიებო ისტორია, თვე/ტიპი ფილტრები, CSV.
• ვადაგადაცილებული გადასახადები, GEL ხარჯი და მხოლოდ მონიშვნა.
• წაშლილები, ვერსიაზე დაბრუნება, JSON შემოტანის წინასწარი ნახვა/გაერთიანება.
• საწყისი ბალანსის თარიღისა და თანხების რედაქტირება.
